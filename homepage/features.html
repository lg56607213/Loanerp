채권 관리

상태 5종으로, 회수가 막힌 건을 먼저

정상·연체·해지·상각·종료. 정상과 연체는 스케줄로 실시간 판정하고, 해지(기한이익상실)·상각·종료는 등록 시점에 확정 저장합니다. 숫자가 갈릴 일이 없습니다.

  • 연체 판정 D+1 · 경과기간 1~30 / 31~60 / 61~90 / 90일 초과
  • 기한이익상실 등록 — 잔여원금 전액 즉시 청구, 미래 회차 청구중지
  • 대손상각 등록 — 충당금 상계·대손상각비 계상, 이자 기산 중단
  • 상각채권 회수는 상각채권추심이익으로 별도 인식
  • 법적절차(지급명령·압류·추심) 진행·비용 관리
청구 · 수납

입금 한 줄이면 충당까지 끝납니다

회차 청구를 생성하고 입금을 등록하면 법정변제충당이 자동으로 적용됩니다. 어느 회차의 무엇에 얼마가 들어갔는지 회차 단위로 남습니다.

  • 충당 순서 — 법적비용 → 지연배상금 → 약정이자 → 원금
  • 상각채권은 법적비용 → 원금 → 이자 순으로 자동 전환
  • 회차별 부분납 추적(미납/부분납/완납/청구중지)
  • 충당 후 남는 금액은 선수금 처리
  • 은행 거래내역 업로드 · 계좌 자동 대사

자동 회계 · 전표

영업을 입력하면 회계가 따라옵니다

수납·지출이 생기면 전표가 자동으로 만들어집니다. 현금이 실제 오갈 때 인식하는 현금주의 기준이라, 국내 중소 대부업 실무에 자연스럽게 맞습니다.

  • 충당 결과 그대로 원금·이자·연체이자를 계정별 분리 기표
  • 일/월 전표 조회, 전표 승인
  • 계정과목(계정) 관리
  • 일계표 · 자금일보로 매일 마감 확인
  • 대부업은 면세라 부가세를 분리하지 않고 총액으로 계상
재무제표 · 영업이익

본업으로 얼마를 벌었는지가 보입니다

  • 재무상태표 · 손익계산서 자동 산출
  • 영업수익 − 영업비용 = 영업이익 단계 표시
  • 대손충당금 · 대손상각비 관리
