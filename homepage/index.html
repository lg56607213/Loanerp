핵심 기능

대부업 업무 전체를 하나로

실제 대부업체의 업무 흐름 그대로 설계했습니다. 필요한 기능만 골라 쓰세요.

📄

여신 관리

대출 등록 → 상환스케줄 생성 → 중도상환 → 만기연장까지 채권 한 건의 전 생애를 추적합니다.

  • 원리금균등 · 원금균등 · 만기일시 상환
  • PMT 자동 산출로 회차별 원금·이자 생성
  • 중도상환 일할 정산, 만기연장·재약정
⚠️

채권 관리

정상·연체·해지·상각·종료 5개 상태로 채권을 추적하고, 회수가 막힌 건을 먼저 보여줍니다.

  • 연체 판정(D+1)과 경과기간 구간 집계
  • 기한이익상실 · 대손상각 등록
  • 법적절차(지급명령·압류·추심) 비용 관리
💳

청구 · 수납

회차 청구를 자동 생성하고 수납을 기록하면 법정변제충당이 자동으로 적용됩니다.

  • 법적비용 → 이자 → 원금 순 자동 충당
  • 회차별 부분납 추적, 잔여원금 자동 갱신
  • 은행 거래내역 업로드 · 계좌 자동 대사
🧾

자동 회계 · 전표

수납·지출이 발생하면 전표가 자동 생성됩니다. 현금주의 기준으로 실무에 맞게.

  • 원금·이자·연체이자를 계정별로 분리 기표
  • 일계표·자금일보로 매일 확인
  • 계정과목·전표 승인 관리
📊

재무제표 · 영업이익

대출채권 이자는 영업수익, 예금이자는 영업외수익. 계정을 나눠 영업이익이 제대로 나옵니다.

  • 재무상태표 · 손익계산서 자동 산출
  • 영업수익 − 영업비용 = 영업이익 단계 표시
  • 차입금 · 대손충당금 관리
🏢

멀티회사 관리

법인·사업장이 여러 개여도 한 계정에서 전환하며 관리합니다. 데이터는 회사별 분리.

  • 여러 회사/사업장 통합 관리
  • 회사별 사용자·권한 설정
  • 회사 간 데이터 완전 분리

회수가 막힌 채권을 먼저 보여줍니다

연체는 납입예정일 다음날(D+1)부터 자동 판정됩니다. 경과기간이 90일을 넘으면 경고를 띄워 기한이익상실·대손상각 검토를 유도합니다. 사람이 기억할 필요가 없습니다.

  • 연체잔액에 기한이익상실 채권도 포함해 집계
  • 90일 초과 건은 대시보드에서 경고
  • 기한이익상실은 담당자 신청으로만 확정(자동 등록 없음)

요금제 자세히 보기
자주 묻는 질문

궁금한 점을 먼저 정리했습니다

지금 엑셀로 관리하던 자료를 옮길 수 있나요?

네. 도입 단계에서 보유 중인 채권·상환스케줄·고객 자료 이전을 지원합니다. 자세한 형식은 상담 때 안내드립니다.

회계를 잘 몰라도 쓸 수 있나요?

수납·지출만 입력하면 원금·이자가 갈려 전표와 재무제표가 자동으로 만들어집니다. 회계 지식 없이도 세무사에 넘길 자료가 정리됩니다. (현금주의 기준)

회사(사업장)가 여러 개인데 각각 관리되나요?

한 계정에서 여러 회사를 전환하며 관리할 수 있고, 회사별 데이터는 서로 분리됩니다.

설치가 필요한가요?

웹 기반이라 별도 설치 없이 브라우저로 접속해 사용합니다. PC·노트북 어디서든 접속됩니다.

요금은 어떻게 되나요?

관리 채권 건수 기준의 월 구독제입니다. 자세한 금액은 요금제 페이지를 참고하세요. (현재 잠정 금액이며, 정식 출시 시 확정됩니다.)

법정 최고이율이나 변제충당 순서도 지켜지나요?

계약 등록 시 약정이율이 연 20%를 넘거나 연체이율이 min(약정이율+3%, 20%)을 넘으면 서버에서 막습니다. 수납 시 변제충당은 법적비용 → 이자 → 원금 순으로 자동 적용되며, 대손상각된 채권은 법적비용 → 원금 → 이자 순으로 바뀝니다. 법 개정에 대비해 상한값은 설정으로 관리합니다.

대부업은 부가가치세 면세인데 세금계산서도 나오나요?

대부업 이자수익은 부가가치세 면세(금융·보험 용역)라 세금계산서를 발행하지 않습니다. 매입 항목도 부가세를 분리하지 않고 총액(공급대가)으로 비용 계상합니다. 대신 청구서를 출력해 드립니다.
